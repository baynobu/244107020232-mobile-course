Silakan simpan file tangkapan layar (screenshot) dari emulator / perangkat fisik ke dalam folder ini dengan nama-nama berikut:

1. `01_home_ai_entry.png`
   - Tangkapan layar halaman utama (`HomePage`) yang menampilkan kartu fitur **"Asisten AI Kampus"** dan tombol **Floating Action Button** di pojok kanan bawah.

   - Tangkapan layar saat dialog pengaturan API Key dibuka (mengetuk tombol ikon kunci di AppBar atau banner).

3. `03_chat_active_conversation.png`
   - Tangkapan layar saat melakukan percakapan interaktif dengan AI mengenai jadwal, KRS, atau informasi kampus lainnya.

4. `04_chat_loading_state.png`
   - Tangkapan layar saat indikator *loading/thinking* ("Asisten AI sedang berpikir...") sedang aktif menunggu balasan dari AI.
